# 接口设计文档

## 全局说明

### 基础信息

- 项目名称：社交动态系统
- BaseURL：`http://localhost:8080`
- Content‑Type
  - JSON接口：`application/json`
  - 文件上传接口：`multipart/form‑data`
- 身份认证：请求头携带 `Authorization: token字符串`，大部分接口需要该token

### 统一返回格式

```
{
  "code": 1,
  "msg": "success",
  "data": {}
}
```

> code：1=成功，0=业务失败；msg：提示信息；data：业务数据，可为对象、数组、字符串、null

### 业务状态说明

- Post.status：0=公开，1=私密，2=仅被关注可见
- 点赞action：0=点赞，1=取消点赞
- 关注action：0=关注，1=取消关注
- relations type：0=关注列表，1=粉丝列表，用于区分获取关注列表/粉丝列表

## 11.添加评论

- 接口路径：`/posts/{id}/comment`
- 请求方式：`POST`
- 认证：需要 Authorization 请求头

### 路径参数

| 参数名 | 类型   | 是否必传 | 说明   |
| :----- | :----- | :------- | :----- |
| id     | string | 是       | 帖子ID |

### 请求Body

（不要加参数名）

| 参数名  | 类型   | 是否必传 | 说明         |
| :------ | :----- | :------- | :----------- |
| content | string | 是       | 评论文本内容 |

### 成功响应示例

```json
{
    "code": 1,
    "msg": "success",
    "data": {
        "avatar": "https://avatars.githubusercontent.com/u/66251174",
        "content": "这条动态不错",
        "createdAt": "2026-11-26T22:15:40.5530123",
        "id": "3edad7b8-6896-4eec-a41e-87a236371437",
        "nickname": "用户2",
        "status": 0,
        "userId": "6b06e8be8e071871e796c2da"
    }
}
```

### 失败响应示例

```
{
  "code": 0,
  "msg": "用户或帖子不存在！",
  "data": null
}
```

## 12.删除评论

- 接口路径：`/posts/{id}/comment/{commentId}`
- 请求方式：`DELETE`
- 认证：需要 Authorization 请求头

### 路径参数

| 参数名    | 类型   | 是否必传 | 说明   |
| :-------- | :----- | :------- | :----- |
| id        | string | 是       | 帖子ID |
| commentId | string | 是       | 评论ID |

### 成功响应示例

```json
{
  "code": 1,
  "msg": "success",
  "data": null
}
```

### 失败响应示例

```json
{
  "code": 0,
  "msg": "没有删除权限！",
  "data": null
}
```

# 文件上传模块接口 /web

## 文件上传到OSS

- 接口路径：`/web/upload`
- 请求方式：`POST`
- Content‑Type：`multipart/form‑data`
- 认证：不需要

### Form表单参数

| 参数名 | 类型          | 是否必传 | 说明              |
| :----- | :------------ | :------- | :---------------- |
| file   | MultipartFile | 是       | 待上传的图片/文件 |

### 成功响应示例

```json
{
    "code": 1,
    "msg": "success",
    "data": "https://vesper-study-java.oss-cn-beijing.aliyuncs.com/2026/11/38ce2894-4324-4824-a57a-e517899367a3.jpg"
}
```

> data 返回上传成功后的文件访问URL字符串
